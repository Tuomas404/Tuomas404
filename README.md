## Projects

- **[Azure Sentinel Honeypot](https://github.com/Tuomas404/azure-sentinel-honeypot)**: internet-exposed Windows Server in Azure, monitored with Microsoft Sentinel. Two custom detection rules (MITRE T1110), both validated with controlled tests. Detected, investigated and closed a real brute-force attack.
- **[Hybrid Identity Lab](https://github.com/Tuomas404/hybrid-identity-lab)**: Active Directory forest on Windows Server 2025 in a local Hyper-V lab. PowerShell automation for onboarding and offboarding, plus least-privilege Help Desk delegation. Entra ID sync is next.
- **osTicket for a school**: support ticket system on Proxmox, published only through a WireGuard VPN behind OPNsense. [Write-up in Finnish](https://tuomas404.github.io/2025/12/08/osticket-oppilaitokselle.html)
